# 云基础设施运营 IOC 第一阶段 UI 计划

## 目标

- 根据 16 张参考图静态还原智算、通算、Region 总览和 Region 下钻四个页面状态。
- 不接后端接口，不建立独立 Mock 层；静态数据、页签和交互状态放入对应 `useXxx.js`。
- 小程序顶部栏不在 H5 中复刻；页面从现有时间筛选行开始，底部导航固定。
- 忽略参考照片的紫色滤镜，以 375px 为主基准并兼容 390px、414px、500px。
- DC 页面和已有筛选 store 保持现有业务行为。

## 实施基线

- 分支：`new-202608`。
- 开始实施时 HEAD：`49dbf8c`，工作区无未提交修改。
- 基线 `npm run build` 通过，仅有既存 vendor CSS/JS 体积告警。

## 公共组件边界

- 精确使用 `echarts@6.0.0`，通过 `echarts/core` 按需注册环形图、柱图、折线图及 SVG 渲染器。
- 先实现 `useECharts.js`、`DonutChart.vue`、`TrendChart.vue`。
- 从 cost-operation 复制 `TableList.vue` 的配置式表格思路，改为移动端列宽和横向滚动，不引入桌面端缩放与分页逻辑。
- 统一实现指标面板、分段页签、趋势值、状态点、排名单元格和底部详情抽屉。
- 图标优先复用 Vant、Element Plus；缺少的业务图标补充 SVG sprite。

## 页面与交互

- 智算：概览、效率、客户分布、Region 分布、Tokens；下划线名称打开详情抽屉。
- 通算：概览、资源页签、客户资源、总量/增量/掉量榜、国内/海外 Region 分布；下划线名称打开详情抽屉。
- Region 总览：经营概览、趋势、国内/海外详情表；仅下划线 Region 名称进入下钻。
- Region 下钻：Region 基础信息、经营指标、服务器、趋势、收入来源、三组 TOP5、客户资源和国内/海外客户榜。
- 底部导航顺序为智算、通算、运营Agent、Region、DC；保留默认 `/commonCompute` 和现有路由名称。

## 代码约束

- 使用单引号，语句末尾添加分号，禁止嵌套三元表达式。
- 不添加业务兜底值；只在图表生命周期、数据转换、路由和抽屉分流等必要逻辑处添加注释。
- 页面只组合公共组件并消费 composable 暴露的响应式数据和行为。
